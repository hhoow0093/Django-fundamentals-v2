# Introduction

## Starting project and creating app
To start creating project in django. inside the root directory of the project, write :
```bash
django-admin startproject mysite .
```

Start creating app by using :
```bash
django-admin startapp polls mysite/polls
```

## Creating views and reusable urls

from the project `urls.py`, include the `polls` urls by adding :

```py
from django.contrib import admin
from django.urls import path
from django.urls import include, path

urlpatterns = [
    path("admin/", admin.site.urls),
    path("polls/", include("mysite.polls.urls"), name="polls"),
]
```

and inside the app `urls.py` include the `views.py` from polls

> urls.py

```py
from . import views
from django.urls import path

urlpatterns = [
    path("", views.index, name="index")
]
```

> views.py

```py
from django.http import HttpRequest, HttpResponse

def index(request: HttpRequest) -> HttpResponse:
    return HttpResponse("hello you are at the polls index")
```
